# 台股籌碼看盤

類似「籌碼K線」的網頁看盤工具，加上每日盤後分析與明日觀察名單。

> 觀察名單是規則式條件篩選的結果，只供研究參考，不構成投資建議。

## 功能

- **看盤**：自選股清單、K 線（MA5/20/60）、成交量、三大法人買賣超、融資餘額、五檔報價。盤中每 5 秒更新。
- **盤後分析**：大盤盤勢判讀（偏多／盤整／偏空）、市場寬度、外資投信買賣超，以及依技術面、籌碼面、基本面打分的觀察名單，每檔都列出加減分理由。

## 安裝與執行

需要 Python 3.10 以上。

```bash
pip install -r requirements.txt
python -m stockapp.collector backfill --days 120   # 第一次回補歷史（上市約 85 個交易日，約 15 分鐘）
python run.py                                       # 開 http://127.0.0.1:8000
```

伺服器開著時，每個交易日 16:45 會自動收集當天資料，21:45 再補融資融券。也可以按右上角「收集今日資料」，或手動執行：

```bash
python -m stockapp.collector today
```

測試：`python -m unittest discover tests`

## 資料來源與限制

| 資料 | 來源 | 時間 |
| --- | --- | --- |
| 盤中報價、五檔 | 證交所 MIS（上市、上櫃） | 約 5 秒延遲 |
| 上市日 K、大盤 | 證交所 MI_INDEX | 收盤後 |
| 上市三大法人 | 證交所 T86、BFI82U | 約 16:00 後 |
| 上市融資融券 | 證交所 MI_MARGN | 約 21:00 後 |
| 上櫃日 K、法人、融資券 | 櫃買 OpenAPI | 只提供最新一天，需每天收集累積 |
| 本益比、殖利率、月營收 | 證交所、櫃買 OpenAPI | 每日／每月 |

- 證交所會封鎖短時間內大量請求的 IP，程式已限制每 3 秒一次，請勿調低。
- 主力分點（券商進出）沒有免費的穩定來源，第一版沒有做。
- 上櫃歷史只能從開始收集那天累積，上櫃 OpenAPI 欄位名稱如有變動，法人與融資券可能需要調整解析。

## 選股評分

基本門檻：收盤 ≥ 10 元、20 日均量 ≥ 1,000 張、收盤站上 MA20。

| 面向 | 加分 | 減分 |
| --- | --- | --- |
| 技術 | 均線多頭排列 +2、站上季線 +1、價漲量增 +1、創 20 日新高 +1 | RSI ≥ 80 −1、月線乖離 ≥ 10% −1 |
| 籌碼 | 投信連買 ≥ 3 天 +2、外資連買 ≥ 3 天 +1、法人 5 日買超占量 ≥ 10% +1、價漲資減 +1 | 法人 5 日賣超占量 ≥ 10% −1、融資 5 日增 > 10% −1 |
| 基本 | 月營收年增 ≥ 20% +2（> 0 為 +1）、本益比 ≤ 20 +1、殖利率 ≥ 4% +1 | 營收年減 ≥ 20% −1、本益比 > 40 −0.5 |

「績優」標籤：月營收年增 > 0 且本益比 ≤ 25。規則都在 `stockapp/analysis.py`，可以自行調整。
