# 台股籌碼看盤

類似「籌碼K線」的網頁看盤工具，加上每日盤後分析與明日觀察名單。

> 偏多／偏空名單是規則式評分的結果，只供研究參考，不構成投資建議。

## 功能

- **看盤**：自選股清單、K 線（MA5/20/60）、成交量、三大法人買賣超、融資餘額、五檔報價。盤中每 5 秒更新。
- **盤後分析**：大盤盤勢判讀（偏多／盤整／偏空）、市場寬度、外資投信買賣超。
- **隔日偏多／偏空名單**：每檔股票依「走勢、法人、大戶、新聞、基本面」五個面向打分，列出明日偏多（可留意）與偏空（宜避開）名單，每條加減分都附理由與相關新聞連結，另有自選股逐檔診斷，以及過去名單的隔日表現（平均漲跌、勝率）。
- **個股盤後診斷**：看盤頁右側顯示目前這檔股票的多空判斷、各面向分數、大戶持股變化與近期新聞。

## 安裝與執行

需要 Python 3.10 以上。

```bash
pip install -r requirements.txt
python -m stockapp.collector backfill --days 120   # 第一次回補歷史（上市約 85 個交易日，約 15 分鐘）
python run.py                                       # 開 http://127.0.0.1:8000
```

伺服器開著時，每個交易日會自動更新：

| 時間 | 動作 |
| --- | --- |
| 16:45 | 收集行情、法人、基本面、集保大戶，抓新聞，產生隔日名單 |
| 19:30 | 更新新聞並重算名單 |
| 21:45 | 補融資融券後重算名單 |
| 08:00 | 開盤前抓隔夜新聞，更新當天名單 |

也可以按右上角「收集今日資料」、盤後分析頁的「更新新聞並重算」，或手動執行：

```bash
python -m stockapp.collector today     # 完整盤後收集 + 報告
python -m stockapp.collector news      # 只更新新聞並重算報告
python -m stockapp.collector holders   # 只更新集保大戶
python -m stockapp.collector report    # 用現有資料重算報告（不連網抓新聞）
```

測試：`python -m unittest discover tests`

## 資料來源與限制

| 資料 | 來源 | 時間 |
| --- | --- | --- |
| 盤中報價、五檔 | 證交所 MIS（上市、上櫃） | 約 5 秒延遲 |
| 上市日 K、大盤 | 證交所 MI_INDEX | 收盤後 |
| 上市三大法人 | 證交所 T86、BFI82U | 約 16:00 後 |
| 上市融資融券 | 證交所 MI_MARGN | 約 21:00 後 |
| 上櫃日 K、法人、融資券 | 櫃買 OpenAPI | 只提供最新一天，需每天收集累積 |
| 本益比、殖利率、月營收 | 證交所、櫃買 OpenAPI | 每日／每月 |
| 大戶持股（股權分散表） | 集保結算所 opendata | 每週五資料，週末公布；只提供最新一週，需每週收集累積 |
| 新聞 | 鉅亨網台股新聞、Yahoo 股市個股 RSS | 盤後與開盤前抓取，保留 30 天 |

- 證交所會封鎖短時間內大量請求的 IP，程式已限制每 3 秒一次，請勿調低。
- 主力分點（券商進出）沒有免費的穩定來源，第一版沒有做。
- 大戶面向需要至少兩週的集保資料才會開始計分，安裝後前兩週大戶分數都是 0。
- 新聞情緒是標題關鍵字比對（例如「接單、創新高、上修」偏多，「衰退、下修、虧損」偏空），簡單透明但會誤判，請點連結看原文。關鍵字在 `stockapp/sources.py` 的 `POS_WORDS`、`NEG_WORDS`。
- 上櫃歷史只能從開始收集那天累積，上櫃 OpenAPI 欄位名稱如有變動，法人與融資券可能需要調整解析。

## 選股評分

門檻：收盤 ≥ 10 元、20 日均量 ≥ 1,000 張。總分 ≥ 4 且站上 MA20、沒有明顯利空新聞列為**明日偏多**；總分 ≤ −3 列為**明日偏空**。

| 面向 | 加分 | 減分 |
| --- | --- | --- |
| 走勢 | 均線多頭排列 +2、站上季線 +1、價漲量增 +1、創 20 日新高 +1 | 均線空頭排列 −2（或跌破月線 −1）、季線之下 −1、價跌量增 −1、創 20 日新低 −1、RSI ≥ 80 −1、月線乖離 ≥ 10% −1 |
| 法人 | 投信連買 ≥ 3 天 +2、外資連買 ≥ 3 天 +1、法人 5 日買超占量 ≥ 10% +1、價漲資減 +1 | 投信連賣 ≥ 3 天 −2、外資連賣 ≥ 3 天 −1、法人 5 日賣超占量 ≥ 10% −1、融資 5 日增 > 10% −1、價跌資增 −1 |
| 大戶 | 400 張大戶持股週增 ≥ 0.5 個百分點 +2（≥ 0.2 為 +1）、4 週累增 ≥ 1 +1、散戶減少且大戶增加 +0.5 | 週減 ≥ 0.5 −2（≥ 0.2 為 −1）、4 週累減 ≥ 1 −1、散戶增加且大戶減少 −0.5 |
| 新聞 | 近 3 日新聞情緒合計 ≥ 1.5 +2（≥ 0.5 為 +1） | ≤ −1.5 −2（≤ −0.5 為 −1） |
| 基本 | 月營收年增 ≥ 20% +2（> 0 為 +1）、本益比 ≤ 20 +1、殖利率 ≥ 4% +1 | 營收年減 ≥ 20% −1、本益比 > 40 −0.5 |

「績優」標籤：月營收年增 > 0 且本益比 ≤ 25。規則都在 `stockapp/analysis.py`，可以自行調整。
